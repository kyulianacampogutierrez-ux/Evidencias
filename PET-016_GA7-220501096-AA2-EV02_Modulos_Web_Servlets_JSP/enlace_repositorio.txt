INSTRUCCIONES DE DESPLIEGUE Y PRUEBA:
1. Iniciar la infraestructura contenerizada:
   $ docker compose up -d db

2. Compilar y empaquetar el artefacto WAR:
   $ docker run --rm -v $(pwd)/PizzeriaWeb:/app -v sena_maven_m2_cache:/root/.m2 -w /app maven:3.9.6-eclipse-temurin-17-alpine mvn clean package -DskipTests

3. El archivo WAR compilado se encuentra en:
   PizzeriaWeb/target/pizzeria-web.war

4. URLs de Acceso a Módulos:
   - Panel Principal: http://localhost:8080/pizzeria-web/index.jsp
   - Directorio de Clientes: http://localhost:8080/pizzeria-web/clientes
   - Catálogo de Pizzas: http://localhost:8080/pizzeria-web/pizzas
   - Gestión de Pedidos: http://localhost:8080/pizzeria-web/pedidos
