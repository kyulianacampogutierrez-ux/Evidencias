3. Desarrollo Práctico Secuencial (Guía de Aprendizaje 7)

3.1. Paso 1: Vinculación del Repositorio Remoto

Se creó un nuevo repositorio público en GitHub con el nombre reglamentario Programa-Git. En la terminal local, dentro del directorio del programa, se inicializó el repositorio local y se asoció la dirección remota mediante el comando git remote add: 

# Inicialización del repositorio local con la rama master
$ git init -b master
Initialized empty Git repository in /home/danilo/Escritorio/Karen/SENA/CDE/Evidencias/PET-015_GA7-220501096-AA1-EV05_Video_Practico_Git/Programa-Git/.git/

# Configuración de identidad de la aprendiz Karen Yuliana Campo
$ git config user.name "Karen Yuliana Campo"
$ git config user.email "karen.campo@sena.edu.co"

# Vinculación del repositorio remoto de GitHub con alias github y origin
$ git remote add github https://github.com/karen-campo/Programa-Git.git
$ git remote add origin https://github.com/karen-campo/Programa-Git.git

# Inspección y verificación de repositorios remotos configurados
$ git remote -v
github  https://github.com/karen-campo/Programa-Git.git (fetch)
github  https://github.com/karen-campo/Programa-Git.git (push)
origin  https://github.com/karen-campo/Programa-Git.git (fetch)
origin  https://github.com/karen-campo/Programa-Git.git (push)

3.2. Paso 2: Carga Inicial de Cambios y Verificación en GitHub

Habiendo estructurado los archivos iniciales del programa (README.md y Main.kt), se generó el primer commit local y se procedió a enviar la rama hacia el repositorio remoto mediante git push: 

# Creación del commit inicial en el repositorio local
$ git add README.md Main.kt
$ git commit -m "feat: commit inicial del proyecto Programa-Git"
[master (root-commit) aea77a8] feat: commit inicial del proyecto Programa-Git
 2 files changed, 20 insertions(+)
 create mode 100644 Main.kt
 create mode 100644 README.md

# Carga de la rama master hacia GitHub
$ git push github master

Verificación en GitHub: Se accedió al portal web de GitHub y se constató la recepción de la rama master conteniendo los dos archivos y el commit aea77a8 en el historial.
