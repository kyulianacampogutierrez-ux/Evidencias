DESCRIPCIÓN DE LA ENTREGA Y EVIDENCIAS INCLUIDAS:
1. TALLER DE INVESTIGACIÓN TÉCNICA:
   - Análisis de arquitectura de software para dispositivos móviles (Android / iOS).
   - Estructura de paquetes de distribución (.apk, .aab), manifest y permisos de seguridad.
   - Seguridad multiusuario en Android: UIDs/GIDs Linux, Sandboxing y principio de menor privilegio.
   - Componentes clave de Android: Activity, Service, BroadcastReceiver, ContentProvider.
   - Comparativa de entornos integrados de desarrollo (Android Studio, VS Code, CLI).

2. ARTEFACTOS Y APLICACIONES MÓVILES GENERADAS:
   - Aplicación Android Nativa (Java POO + Android SDK API 34+):
     Código fuente en carpeta app_nativa_android/ y APK compilada para Android 14+.
   - Aplicación Móvil React Native (Hermes + Fabric C++ Engine):
     Código fuente en carpeta app_react_native/ y APK standalone release con bundle JS embebido.

3. AMBIENTE DE CONSTRUCCIÓN AISLADO (DOCKER):
   - Imagen Docker de compilación (pizzeria-android-builder:34) con OpenJDK 17, Gradle 8.5/9.4.1
     y Android SDK CLI sin requerir Android Studio ni emuladores en la máquina anfitriona.

4. OBSERVACIÓN INSTITUCIONAL:
   - Se prescindió de Android Studio por optimización de espacio y rendimiento; se utilizó
     Visual Studio Code como IDE principal y Docker para la generación de binarios.
   - Se adjuntan ambos ejecutables: APK nativa (resolución de guía) y APK React Native release
     (proyecto formativo Pizzería Gourmet Bella Italia Popayán).
