🌐 ¿Cómo verificar si un dominio está bien configurado?

Mediante consultas DNS con utilidades como dig, nslookup y whois, verificando registros A (dirección IPv4), CNAME (alias canónico www), MX (enrutamiento de correo) y TXT / SPF. Además se valida la propagación DNS mundial, estado de redirección canónica 301 forzada a HTTPS y la validez de la cadena del certificado SSL/TLS con openssl s_client.

🧭 ¿Una aplicación web se ve igual en todos los navegadores?

No necesariamente. Existen discrepancias debidas a los distintos motores de renderizado: Blink (Google Chrome, MS Edge), Gecko (Mozilla Firefox) y WebKit (Apple Safari). Requiere pruebas de compatibilidad Cross-Browser, normalización de estilos CSS (CSS Reset/Normalize), prefijos de proveedor y verificación de soporte en CanIUse.

📱 ¿Cómo se ve una aplicación web en el explorador del celular?

Debe responder al paradigma Mobile-First y Responsive Web Design (RWD) mediante la etiqueta meta viewport, Media Queries CSS y rejillas fluidas (Flexbox / CSS Grid). Se valida que los elementos táctiles (*touch targets*) midan al menos 48×48 px, las tipografías sean legibles y los menús colapsen en modo hamburguesa sin desbordamiento horizontal.

🎯 ¿Qué elementos se deben probar en una aplicación web?

Se prueba: 1) Navegación y enlaces (sin rutas rotas 404), 2) Formularios y validaciones de datos (regex, requeridos, saneamiento XSS), 3) Flujo transaccional de negocio (cálculo de órdenes, 8% impoconsumo en COP), 4) Persistencia e integridad en base de datos (MySQL), 5) Rendimiento y cabeceras de seguridad OWASP.
