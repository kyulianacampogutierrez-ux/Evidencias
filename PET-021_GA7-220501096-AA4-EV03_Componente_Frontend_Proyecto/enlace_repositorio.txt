DESCRIPCIÓN DEL MÓDULO FRONT-END:
Aplicación de Página Única (SPA) construida en React 18, modularizada según la metodología
Atomic Design en 11 componentes desacoplados, con gestión de estado global reactivo mediante
Context API (CartContext y AuthContext), validación estricta de checkout con expresiones
regulares, comanda interactiva de cocina y consumo asíncrono de la REST API de Spring Boot
desplegada en Docker en el puerto 8082.
