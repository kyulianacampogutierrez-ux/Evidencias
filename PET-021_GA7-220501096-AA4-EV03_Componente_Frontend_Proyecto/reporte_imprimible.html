1. Introducción

El presente informe documenta la codificación integral y puesta en marcha del módulo front-end del proyecto formativo Pizzería Bella Italia, en cumplimiento riguroso de la evidencia GA7-220501096-AA4-EV03. Siguiendo las directrices del diseño de interfaz previo y la arquitectura de microservicios establecida, se desarrolló una Single Page Application (SPA) moderna con el framework React 18 y Vite.

La aplicación implementa una arquitectura modular basada en Atomic Design, separando responsabilidades mediante Custom Hooks y administrando el estado global con la Context API de React. Además, se integra de forma desacoplada con el microservicio backend REST desarrollado en Spring Boot 3 desplegado en contenedores Docker (puerto 8082), ofreciendo tanto la experiencia de compra para comensales como el control de comandas para la cocina.

2. Objetivos

2.1 Objetivo General

Codificar e implementar el módulo front-end del proyecto formativo Pizzería Bella Italia utilizando el framework React-JS, aplicando estándares de codificación limpia, gestión de estado global reactivo, validaciones síncronas de datos y consumo de servicios web RESTful.

4. Especificación Técnica de los Módulos Principales

4.1 Gestión de Estado Global con CartContext

El componente CartContext.jsx provee un almacén centralizado para la comanda de compra, garantizando que cualquier mutación se ejecute de forma estrictamente inmutable sin alterar el estado anterior. Los totales monetarios e impuestos se calculan dinámicamente mediante useMemo:

// Cálculo memorizado de totales en CartContext.jsx const subtotalCOP = useMemo(() => { return items.reduce((acc, it) => acc + it.subtotal, 0); }, [items]); const freeShippingEligible = useMemo(() => { return subtotalCOP >= FREE_SHIPPING_THRESHOLD; // $50.000 COP }, [subtotalCOP]); const shippingCOP = useMemo(() => { if (subtotalCOP === 0) return 0; return freeShippingEligible ? 0 : SHIPPING_COST; // $6.000 COP }, [subtotalCOP, freeShippingEligible]);

4.2 Validación en Tiempo Real en CustomerFormModal

En cumplimiento de las normas de validación de datos de entrada, el modal de checkout implementa una verificación síncrona estricta antes de emitir la transacción hacia el backend:

  • Nombre Completo: Mínimo 3 caracteres alfabéticos obligatorios.
  • Celular Colombiano: Expresión regular /^3[0-9]{9}$/ que valida exactamente 10 dígitos numéricos iniciando con el dígito 3.
  • Dirección de Domicilio: Longitud mínima de 5 caracteres con retroalimentación visual accesible.

4.3 Integración Asíncrona con el Microservicio Spring Boot

El módulo api.js centraliza todas las comunicaciones HTTP asíncronas con el backend en http://localhost:8082/api, incorporando controladores de aborto con timeout (3000ms) y catálogo semilla de respaldo (*Graceful Fallback*) para permitir la ejecución autónoma en entornos de evaluación:

// Cliente HTTP asíncrono en api.js export const getPizzas = async () => { try { const controller = new AbortController(); const timeoutId = setTimeout(() => controller.abort(), 3000); const response = await fetch('http://localhost:8082/api/pizzas', { signal: controller.signal }); clearTimeout(timeoutId); if (!response.ok) throw new Error(`HTTP error ${response.status}`); return await response.json(); } catch (error) { console.info('Usando catálogo semilla local:', error.message); return FALLBACK_PIZZAS; } };
