🔄 HU-04: Flujo Operativo y Transición de Estados de Despacho (PATCH)
✓ CASO DE PRUEBA APROBADO

Requisito: Permitir actualizar el estado del pedido a lo largo del ciclo de vida gastronómico (*En Preparación -> En Horno -> En Reparto -> Entregado*).

Actualización Parcial con Método PATCH
PATCH /api/pedidos/4/estado?nuevoEstado=En Horno
// Cabecera:
PATCH /api/pedidos/4/estado?nuevoEstado=En+Horno HTTP/1.1
Host: localhost:8082
Content-Length: 0
Respuesta con Estado Actualizado
HTTP/1.1 200 OK
{
  "idPedido": 4,
  "total": 110000.00,
  "estado": "En Horno", // Estado confirmado
  "fechaPedido": "2026-11-08 18:28:25"
}
