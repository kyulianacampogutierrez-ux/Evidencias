1. Introducción y Contexto de la Evidencia

El desarrollo de interfaces gráficas modernas para aplicaciones web y móviles exige no sólo habilidades de codificación, sino una profunda comprensión de la interacción humano-computador, la arquitectura de la información y la semiótica visual. En el marco de la Guía de Aprendizaje 6 del programa ADSO, la evidencia GA6-220501096-AA4-EV01 tiene como finalidad evaluar la apropiación de los fundamentos técnicos de HTML5, hojas de estilo en cascada (CSS3) y comportamientos interactivos con JavaScript.

📌 Requerimiento Textual de la Guía 6 (Pág. 12-13):
"Con base en el siguiente contexto, aplique los principales componentes de HTML y CSS: elabore una página que enseñe un pequeño tutorial seleccionando un tema de su gusto. Establezca un título y emplee una lista ordenada para indicar los distintos conceptos que contiene el tutorial con enlaces a los temas propiamente dichos. Cada tema debe tener su título, imagen y la descripción del tema. Debe incluir los elementos vistos en el componente y utilizar estilos CSS."

1.1 Tema Seleccionado y Justificación

Para garantizar máxima cohesión con el proyecto formativo de la Pizzería Bella Italia, se diseñó el "Tutorial Didáctico: Fundamentos de Componentes Frontend para Aplicaciones Web y Móviles", el cual toma como base teórica directa el componente formativo institucional CF16: Herramientas para el diseño y desarrollo móvil híbrido.

2. Arquitectura de la Solución y Temario Pedagógico

Cumpliendo estrictamente la instrucción de utilizar una lista ordenada (<ol>) como índice interactivo con enlaces internos (href="#tema-X"), el tutorial se estructuró en 6 bloques temáticos integrales:

N° Tema Desarrollado Conceptos Clave del Componente Formativo Recurso Visual
01 Anatomía Semántica con HTML5 header, nav, main, section, article, figure, footer. Accesibilidad web. Diagrama vectorial SVG de layout semántico.
02 Tipografía y Jerarquía Visual Fuentes Sans-serif legibles, escala escalada (sp / rem), line-height de 1.6. Escala comparativa de encabezados H1-H3 y cuerpo.
03 Retícula de 8dp y Margen de 16dp Sistema modular de múltiplos de 8px, padding de 16dp, consistencia matemática. Matriz de espaciado modular con cotas visuales.
04 Teoría del Color y Semiótica Colores reservados (Rojo, Amarillo, Verde) y señaléticos (Azul, Blanco, Negro). Paleta semiótica con contraste accesible WCAG AA.
05 Iconografía y Ley de Fitts Botones táctiles ≥ 48px, dimensiones semiótica, semántica y funcional. Diagrama de zonas de alcance ergonómico.
06 Estructura de Navegación y DCU Navegación lineal, jerárquica y aleatoria. Ciclo de 4 fases norma ISO 13407. Infografía del ciclo de Diseño Centrado en el Usuario.

3.2 Estilos CSS3 (Retícula Modular y Modo Oscuro)

Se implementó un sistema de diseño con variables nativas en :root, asegurando el cumplimiento de la regla de los 8dp y compatibilidad con Modo Oscuro (Dark Theme):

:root { --space-sm: 8px; /* Módulo base 1x */ --space-md: 16px; /* Margen lateral 2x */ --space-lg: 24px; /* Espaciado de secciones 3x */ --space-2xl: 48px; /* Altura mínima táctil (Ley de Fitts) */ /* Paleta cromática semiótica */ --color-danger: #ef4444; /* Error / Peligro */ --color-warning: #f59e0b; /* Precaución */ --color-success: #10b981; /* Éxito */ --color-primary: #0284c7; /* Azul señalético */ }

3.3 Interactividad con JavaScript Modular

  • Buscador en tiempo real: Filtra instantáneamente las tarjetas temáticas a medida que el usuario escribe.
  • Modo Claro / Oscuro: Permite alternar la interfaz con persistencia en localStorage.
  • Barra de lectura: Mide el desplazamiento vertical del documento y anima la barra de progreso superior.
  • Copiador de código: Facilita copiar los fragmentos de código con retroalimentación visual al usuario.

6. Conclusiones

1. La implementación de una estructura semántica en HTML5 no solo optimiza la accesibilidad y el posicionamiento web, sino que establece una base limpia para la aplicación de estilos y mantenimiento del código a largo plazo.

2. La adopción de la retícula de 8dp y el respeto a la Ley de Fitts garantizan que las interfaces móviles sean ergonómicas, reduciendo errores de digitación por parte de los usuarios al interactuar con botones y campos de entrada.

3. La metodología TDD (Desarrollo Guiado por Pruebas) demostró ser una práctica altamente eficaz para verificar de manera objetiva e inmediata que cada requerimiento pedagógico y técnico exigido por el SENA se cumpla en su totalidad.
