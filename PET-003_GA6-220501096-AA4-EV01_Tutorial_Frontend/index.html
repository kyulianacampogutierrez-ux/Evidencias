Tema 01 • Estructura ⏱️ 3 min de lectura

Tema 1: Anatomía y Estructura Semántica con HTML5

En lugar de abusar de etiquetas genéricas como <div> para todo, HTML5 introdujo etiquetas semánticas que describen explícitamente su significado tanto para los desarrolladores como para los navegadores y lectores de pantalla para personas con discapacidad visual.

💡 Analogía para mortales:

Pensar en la estructura semántica es como armar el esqueleto humano. Si todo fueran huesos iguales (etiquetas <div>), no sabrías dónde va la cabeza ni las piernas. Las etiquetas semánticas como <header>, <nav>, <main> y <footer> le dan a cada parte su nombre y función natural.

HTML5 Semántico 
<header>
  <h1>Pizzería Bella Italia</h1>
</header>

<nav aria-label="Menú principal">
  <ol>
    <li><a href="#tema-1">Estructura Semántica</a></li>
    <li><a href="#tema-2">Tipografía y Escala</a></li>
  </ol>
</nav>

<main>
  <section>
    <article class="tema-card">
      <h2>Título del Contenido</h2>
      <p>Explicación clara del tema...</p>
    </article>
  </section>
</main>

<footer>
  <p>Desarrollado por Karen Campo - ADSO 228118</p>
</footer>
Tema 02 • Tipografía ⏱️ 3 min de lectura

Tema 2: Tipografía, Jerarquía Visual y Legibilidad

El componente formativo del SENA señala que en dispositivos modernos y pantallas móviles, el uso de tipografías limpias y abiertas (Sans-serif) es esencial porque evita la fatiga visual. Además, la escala no debe ser arbitraria: los textos de lectura deben mantener un mínimo de 16px (1rem), los encabezados principales oscilar entre 28px y 34px, y el interlineado (line-height) debe situarse entre 1.5 y 1.6.

💡 Analogía para mortales:

La jerarquía tipográfica es como un periódico impreso: con una mirada de 2 segundos, tus ojos saben cuál es la noticia principal por su gran titular, de qué trata cada columna por los subtítulos y dónde está el detalle fino del texto.

CSS3 Jerarquía Tipográfica 
:root {
  --font-main: 'Plus Jakarta Sans', -apple-system, sans-serif;
  --font-mono: 'JetBrains Mono', monospace;
  --fs-h1: 2rem;      /* 32px */
  --fs-h2: 1.375rem;  /* 22px */
  --fs-body: 1rem;    /* 16px */
  --line-height: 1.6;
}

body {
  font-family: var(--font-main);
  font-size: var(--fs-body);
  line-height: var(--line-height);
  color: #1e293b;
}
Tema 03 • Espaciado ⏱️ 3 min de lectura

Tema 3: Retícula Espacial (Grid de 8dp) y Margen de 16dp

El componente formativo del SENA destaca que "se debe utilizar un módulo de espaciado y separación de 8dp, siendo común tener márgenes laterales de 16dp". Al diseñar bajo esta regla matemática, todo elemento gráfico (botones, tarjetas, espaciado entre párrafos e íconos) se escala armoniosamente en cualquier pantalla.

💡 Analogía para mortales:

Imagina escribir en un cuaderno cuadriculado donde cada cuadrito mide 8 milímetros. En vez de poner márgenes al azar de 7mm o 13mm que desalinean todo, usas 1 cuadro (8px), 2 cuadros (16px) o 3 cuadros (24px). El resultado se ve ordenado y profesional al instante.

CSS3 Retícula de 8dp 
:root {
  --space-1: 8px;   /* Módulo base 1x */
  --space-2: 16px;  /* Margen lateral 2x */
  --space-3: 24px;  /* Separación secciones 3x */
  --space-4: 32px;  /* Separación bloques mayores 4x */
}

.container {
  padding-left: var(--space-2);   /* Margen lateral 16dp */
  padding-right: var(--space-2);
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: var(--space-2);            /* Espacio de 16dp */
}
Tema 04 • Teoría del Color ⏱️ 3 min de lectura

Tema 4: Teoría del Color, Contraste y Significado Semiótico

El componente formativo define el código cromático señalando que los colores son simultáneamente "color y signo", pues conllevan un mensaje intrínseco:

  • Rojo: Color reservado para advertir peligro, fallos y errores del sistema.
  • Amarillo: Color reservado para prevención, advirtiendo consecuencias antes de una acción.
  • Verde: Color reservado para éxito, validación y confirmación satisfactoria.
  • Blanco, Negro y Azul: Colores señaléticos que estructuran la información y guían la navegación.
💡 Analogía para mortales:

Es igual que un semáforo de tránsito: si una aplicación te muestra un botón de "Aceptar" en color rojo chillón y el de "Cancelar" en verde, tu cerebro se confunde inmediatamente porque esos colores ya tienen un significado cultural grabado en la mente humana.

Variables de Color Semiótico 
:root {
  /* Colores Reservados */
  --color-danger: #ef4444;    /* Error y alertas críticas */
  --color-warning: #f59e0b;   /* Prevención y atención */
  --color-success: #10b981;   /* Aprobación y éxito */
  
  /* Colores Señaléticos */
  --color-primary: #0284c7;   /* Azul para botones y enlaces */
  --color-bg-dark: #0f172a;   /* Negro/Gris fondo oscuro */
  --color-text-dark: #f8fafc; /* Blanco para texto accesible */
}
Tema 05 • Ergonomía e Íconos ⏱️ 4 min de lectura

Tema 5: Iconografía, Semiótica y Ley de Fitts

La Ley de Fitts es un principio ergonómico fundamental: describe que el tiempo que un usuario tarda en alcanzar un objetivo con el dedo o el ratón depende del tamaño del objetivo y de la distancia hasta él. Por esta razón, los botones de acción principal deben medir al menos 48x48 píxeles en dispositivos táctiles y situarse en zonas de fácil alcance (como las esquinas o la parte inferior).

Por su parte, los íconos operan bajo tres dimensiones críticas:

  • Dimensión Semiótica: Similitud con el objeto real (un lápiz para editar, una papelera para eliminar).
  • Dimensión Semántica: Unificación visual (todos los íconos comparten el mismo grosor de trazo o estilo).
  • Dimensión Funcional: Comunica la acción sin necesidad de un manual de usuario.
💡 Analogía para mortales:

Un botón de 20 píxeles en el celular es como intentar tocar con guantes de boxeo un botón microscópico: vas a fallar y a presionar otra cosa por error. Con botones de 48px con buen espacio alrededor, puedes comprar una pizza con una sola mano mientras caminas sin equivocarte.

CSS3 Botón Ergonómico Fitts 
.btn-tactil {
  min-height: 48px;              /* Cumple la Ley de Fitts */
  min-width: 48px;
  padding: 12px 24px;
  border-radius: 8px;            /* Múltiplo de 8dp */
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: 8px;
  cursor: pointer;
  transition: transform 0.15s ease, background-color 0.2s ease;
}

.btn-tactil:hover {
  transform: translateY(-2px);   /* Microinteracción táctil */
}
Tema 06 • Arquitectura y DCU ⏱️ 4 min de lectura

Tema 6: Estructura de Navegación y DCU (ISO 13407)

El estándar ISO 13407 establece el marco del Diseño Centrado en el Usuario (DCU) a través de cuatro etapas iterativas: entender el contexto de uso, especificar los requisitos del usuario, producir prototipos y evaluar los diseños con pruebas continuas.

Respecto a las estructuras de navegación, se clasifican en:

  • Lineales: Secuencia paso a paso obligatoria (como los carritos de compra o wizards de bienvenida).
  • Jerárquicas: Estructura en árbol donde el usuario elige categorías antes de profundizar (como la carta de pizzas y bebidas).
  • Aleatorias: Libre exploración según el interés espontáneo del visitante.
💡 Analogía para mortales:

El DCU es como cocinar para tus invitados preguntándoles qué alergias tienen antes de comprar los ingredientes, en lugar de preparar un plato exótico al azar y descubrir en la mesa que nadie puede comerlo.

JavaScript Interactivo de Navegación 
// Navegación suave con compensación de altura del encabezado
document.querySelectorAll('a[href^="#"]').forEach(link => {
  link.addEventListener('click', function(e) {
    e.preventDefault();
    const target = document.querySelector(this.getAttribute('href'));
    if (target) {
      const headerOffset = 80;
      const elementPosition = target.getBoundingClientRect().top;
      const offsetPosition = elementPosition + window.pageYOffset - headerOffset;

      window.scrollTo({
        top: offsetPosition,
        behavior: 'smooth'
      });
    }
  });
});

📖 Glosario de Conceptos Frontend (SENA CF16)

Estándar ISO 13407
Marco internacional que guía el ciclo de vida de desarrollo de software bajo los principios del Diseño Centrado en el Usuario (DCU).
Ley de Fitts
Principio de ergonomía que postula que el tiempo necesario para mover el dedo o ratón a un botón depende de su distancia y de su tamaño físico.
Retícula de 8dp
Métrica modular donde todas las dimensiones, márgenes y separaciones se definen como múltiplos exactos de 8 píxeles.
Skeumorfismo
Estilo de diseño gráfico que imita texturas y objetos de la vida real (como interruptores de palanca o texturas de cuero) para generar familiaridad.
Píxel Escalado (sp / rem)
Unidad tipográfica relativa que se adapta proporcionalmente a la configuración de accesibilidad del usuario y a la densidad de la pantalla.

Proyecto Formativo
