3.1. Automatización Dinámica del Token JWT en Postman

En la pestaña Tests de la petición de Login Exitoso (TC-04), se implementó el siguiente script en JavaScript que extrae el token emitido por el backend y lo inyecta automáticamente en la variable de entorno, permitiendo que las peticiones protegidas posteriores se ejecuten sin intervención manual: 

// Captura automática de JWT en Postman Test Script
pm.test("Autenticación satisfactoria y guardado dinámico de token", function () {
    pm.response.to.have.status(200);
    var res = pm.response.json();
    pm.expect(res.mensaje).to.eql("Autenticación satisfactoria");
    pm.expect(res.token).to.be.a("string");
    
    // Asignación transparente para las peticiones subsecuentes
    pm.environment.set("jwt_token", res.token);
});
